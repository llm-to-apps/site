## Pattern

Name: Real-Time / Operations Landing

Conversion focus: demo/sandbox/trust-driven operations product.

CTA placement:

- primary CTA in nav
- repeated CTA after metrics or product proof

Color strategy:

- dark or neutral base
- status colors for operational meaning
- data-dense but scannable

Recommended section order:

1. Hero with product/live preview or status
2. Key metrics and indicators
3. How it works
4. CTA

## OS7 Interpretation

For OS7, this means:

- The hero should show a live OS builder cockpit.
- The user intent should be visible as a command.
- Generated apps, databases, dashboards, and workflows should appear as system modules.
- Status indicators should make the page feel alive.
- Motion should communicate building/syncing/generation, not just decoration.
